# ADR 0001: 范围与存储分层

## 状态

已采纳。行情恢复与公告日财务来源已完成真实数据验证；R2 的估值和评分实际体积仍待验证。

## 决定

- D1 Free `quant-core` 只保存 `stock_latest`、同步状态、当前板块状态、候选和轻量审计数据。
- R2 `quant-history` 保存按股票/年份压缩的十年行情、估值、评分和冷历史。
- Python pipeline 在本地 staging SQLite/Parquet 中计算，不在 Worker 请求过程中全市场计算因子。
- 初始十年导入在本地分片、可中断地执行；GitHub Actions 只负责增量同步和补漏。
- 初始 V1 的严格表现统计从上线后保存的不可变候选开始。

## 原因

全市场十年行情、估值和评分会超过单个免费关系数据库的可靠容量。将查询频繁且数据量小的最新快照放入 D1，将追加型历史归档为 R2 对象，可以将数据库写入和容量维持在免费额度附近。

## Gate

Phase 0 必须验证：

1. 核心日行情最近 20 个完整交易日覆盖率不低于 99%。
2. R2 十年容量外推小于 8 GB。
3. 五日缺口在 90 分钟内可以恢复。
4. 财务数据具有可靠公告日，否则历史基本面评分降级为上线后启用。

## 已知限制

AKShare 的 Tencent 与 Sina 历史日线备用源已覆盖当前沪深北交易代码，但不保证旧三板代码历史可得。旧三板/退市股缺失时必须在历史研究页面标注幸存者偏差，不能作为当前市场同步失败的理由。
